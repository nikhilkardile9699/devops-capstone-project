## Project Description

The Accounts Microservice is a RESTful web application that provides account management functionality.

This project demonstrates modern DevOps practices by implementing Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions, Docker, Kubernetes, and Tekton.

## Key Features

- Create an account
- Read account details
- List all accounts
- Update account information
- Delete an account
- Automated testing using GitHub Actions
- Security implementation using Talisman and CORS
- Docker containerization
- Kubernetes deployment
- Automated deployment using Tekton

## Technologies Used

- Python and Flask
- GitHub and GitHub Actions
- Docker
- Kubernetes
- Tekton
- Nose tests
- Talisman and CORS

## Project Objective

To develop, secure, containerize, and deploy a RESTful Accounts Microservice using modern CI/CD and DevOps technologies.
